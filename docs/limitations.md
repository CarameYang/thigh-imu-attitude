## 2. 六轴 IMU 的固有限制 / Inherent six-axis limits

| 限制 | 后果 |
|---|---|
| **无绝对航向参考** | 世界水平朝向不是真北；航向随零偏漂移，静止段也会累积转动 |
| **沿重力的零偏不可观测** | 该分量表现为**纯航向漂移**，只能由静止数据估计 |
| **绕传感器 x 轴的 180° 不可观测** | 六轴下两种安装方式产生相同观测；需磁力计或 UWB 复核 |
| **零偏随温度与时间变化** | 不同会话不沿用同一组零偏；同一会话内也未建模其变化 |
| **加速度计测的是比力** | 静止时读数约 +9.81 m/s² 而非零；自由落体时才接近零 |
| **加速度计同时被用于姿态与输出** | 静止残差只能证明**内部一致性**，不能独立证明动态精度 |

## 3. 大腿安装的特殊限制 / Thigh-mount specifics

- 大腿在行走中的**低动态**（摆动相）与真正的静止难以区分。
- **双脚未换位置、身体回到原处、原地晃动**，都**不保证** IMU 瞬时速度为零。
- 因此本仓库的静止检测是**候选**机制，阈值策略明确写了"验证差也不自动放宽"。
- 已知澄清：某次实时实验约 **34.5 s** 处是"身体小幅晃动、双脚未换位置"，
  **不能**描述为"已证实的静止漏检"。该澄清**只适用于该录制该区间**。
- 另一录制 `20261012_003433_121271_live` 的 **2–6 s** 由用户明确确认静止，
  该事实保留，**不扩展到其它时间**。

## 4. 数据与时间限制 / Data and timing limits

| 限制 | 说明 |
|---|---|
| 节点与电脑时钟**未同步** | 姿态积分用节点时间差；电脑收包抖动（曾出现约 221 ms）不可当作运动 |
| 内部 ODR、精确采样时刻未验证 | 节点时间戳近似"读取开始时刻"，非硬件采样时间戳 |
| 端到端延迟未测 | 实时性结论不可用于闭环控制 |
| 跨节点同步未验证 | 多节点场景（如 IMU + UWB 标签）尚不具备时间对齐基础 |
| 长期稳定性未验证 | 只验证过短时录制 |
| 动作无精确真值 | 区间秒数是电脑接收相对时间，动作角度由用户描述 |

## 5. 误差累积的后果 / Why residual size matters

即使平均只有 **0.07 m/s²** 的恒定偏差，持续 10 s：

```text
速度误差 ≈ 0.07 × 10      = 0.7 m/s
位置误差 ≈ 0.5 × 0.07 × 10² = 3.5 m
```

这是**说明累积效应的数学例子，不是本实验已测得的位移**。
已有实测残差中含**持续偏差**（手持窗口 X 均值 −0.1814）与**瞬时尖峰**
（1.6862 / 1.0920），二者都会进入积分。

## 6. 测试覆盖的边界 / What the tests do not cover

- 49 项测试覆盖**计算行为与输入保护**（坐标旋转、偏置扣除、真实线加速度保留、
  拒绝非法数值、时间倒退、断流超时等）。
- **不覆盖**：真实人体运动下的精度、传感器故障模式、长期漂移、温度影响、
  网络丢包对估计的实际影响。
- 其中 **11 项依赖本地录制数据**，克隆本仓库后无法运行（数据按政策不入库）。
- 单元测试通过**不能**替代有独立真值的实验验证。

## 7. 参数与阈值不是普适结论 / Parameters are not universal truths

| 参数 | 现状 |
|---|---|
| 检测阈值 | 各训练区间 99% 分位 × 1.5 并取下限 `[0.06, 0.15, 0.2]`——**工程初始值** |

| 重力常数 9.80665 | 标准值，未做本地重力测量 |

## 8. 结论在什么情况下会失效 / When these conclusions expire

以下任一变化都需要重新评估，**不能沿用旧结论**：

- 更换硬件（如按计划改用 ICM-42688-P）或更换固件版本。
- 修改安装方式或佩戴位置。
- 修改坐标、符号、四元数约定或单位。
- 修改姿态参数、检测阈值或固定模型。
- 录制条件变化（网络、供电、温度、长时间运行）。
- 原始数据被重新解析或重新保存。

> 项目纪律：**发现差异要记录依据，不暗中重写历史结论。**
> Record the new evidence; never silently rewrite past conclusions.

## 10. 与团队分工相关的边界 / Ownership boundary

- 本仓库负责 **IMU 子模块**；用户明确负责 IMU，**不默认承担整体融合**。
- 真正的 **ZUPT 速度更新**、**修正状态接口**、**时间/坐标对齐**需要与
  融合负责人确认，尚未确定。
- UWB、ESKF、后端、UI、MCAP 回放属于完整系统的其他部分。
- 接口、坐标与数据包字段有差异时，**以主线仓库契约为准**。

## 2. 三类工作要分清 / Three kinds of work

| 类别 | 含义 | 能证明什么 |
|---|---|---|
| **真实硬件实验** | 佩戴/放置传感器并实际录制 | 真实数据行为；受动作无精确真值限制 |
| **离线回放/复算** | 用保存的数据重跑当前代码 | 算法可复现、内部一致性；**不是**新的硬件实验 |
| **软件单元测试** | 用已知输入的合成用例 | 计算与输入保护符合预期；**不**证明真实运动精度 |

> ⚠️ **反复强调的纪律**：复现旧数据不等于重新完成一次独立实验；
> 单元测试通过不等于定位精度通过。

## 4. 2026-10-12 的四份固定录制 / The four fixed recordings

这四份是姿态与去重力验证的主要依据，合计 **13,478** 个有效包。
动作时间均为**电脑接收相对时间**（0 = 首包），已用自动识别的静止平台核对。

### ① `20261012_003433_121271_live` —— 大腿慢转体

- **命令**：`--duration 90 --notes "Thigh mounting + slow 90deg body rotation validation"`
- **动作**：站立不动 20 s → 绕竖直轴**慢慢**转体约 90°（约 10 s）→ 停 10 s →
  正常走 10 s → 再站立 20 s（实际在 83.8 s 手动停止）
- **实测**：4190 包、83.8 s、无超时；站立段 2–19.5 / 31–39.5 / 51–70 s，
  安装倾角 **6.71° / 6.87° / 7.90°**；转体段陀螺积分 90.9°，但比力方向仅变 0.44°
  （模块近竖直，重力对该转动的灵敏度只有 6.9°）
- **可证明**：姿态滤波、安装倾角重复性
- **不可用于**：判定安装轴向（转体几乎不改变重力方向）

### ② `20261012_004616_059007_live` —— 桌面绕 +Y 转动

- **命令**：`--duration 60 --notes "Table gyro check: +/-90deg about module +Y"`
- **动作**：平放静止 10 s → 绕模块 +Y 慢转 90°（约 10 s）→ 停 6 s →
  反向转回 90° → 停 12 s
- **实测**：3002 包、60.0 s；静止平台 2–9.5 / 22–29 / 45–59 s；
  两次转动陀螺积分 **90.86°** 与 **71.38°**，由姿态反推 82.72° 与 74.82°
  （幅度比 1.035 / 0.992）
- **可证明**：陀螺符号、手性、刻度；桌面基准姿态

### ③ `20261012_024655_838538_live` —— 桌面绕丝印 x 轴翻转

- **命令**：`--duration 70 --notes "Verify sensor +X sign: face-up flat, roll about silk x by +/-90"`
- **动作**：平放（丝印朝上、x 箭头朝前）静止 8 s → 抬右手边长边绕 x 翻 90° →
  停 8 s → 翻回 → 停 → 抬左手边长边反向翻 90° → 停 → 翻回 → 停
- **实测**：3300 包、66.0 s；平台 0–7（平放，`az ≈ +9.88`）/ 17–19（+y 朝天）/
  28.5–31.5 与 34.5–36.5（回平放）/ 44.5–50（−y 朝天）/ 56–66（回平放）；
  四个转动区间幅度比 1.035 / 0.992 / 1.010，符号与手性全部一致
- **可证明**：丝印三轴为正常右手系、加速度计输出为比力、陀螺符号与刻度
- **关键作用**：与站立段一起构成**安装方向判定**的依据

### ④ `20261012_025851_252946_live` —— 坐姿手持摆腿

- **命令**：`--duration 70 --notes "Seated thigh swing: horizontal then down to near vertical, x2"`
- **动作**：坐姿，仅动髋关节，大腿在**水平 ↔ 接近竖直**之间摆动两次，
  每段静止约 6 s。**模块拿在手里，不是绑在大腿上**（用户说明）
- **实测**：2986 包、59.7 s；平台 4.5–6.5 与 8.5–10（水平，`az ≈ +9.88`）/
  19–21（竖直，`ax ≈ +9.78`）/ 28–29.5 与 30.5–32.5（水平）/ 39–41 与 41.5–44（竖直）/
  51.5–56（水平）；四个转动区间（绕传感器 y）幅度比 1.014 / 0.997 / 1.017 / 0.992，符号一致
- **可证明**：绕 y 轴转动的一致性交叉检查
- **不可用于**：安装方向判定（**手持朝向由手决定**）

### 三处重点残差 / Three notable residuals

| 位置 | 现象 | 已分析到哪一步 |
|---|---|---|
| 手持 025851，8.5–10 s | X 均值 −0.1814、RMS 0.2123；约 **93%** 样本为负 | 残差分解：**方向项**贡献约 −0.17969，**幅值项**约 −0.00174 → 调重力常数无法解决；**不单独证明姿态错了** |
| 大腿 003433，约 35.028 s | Z 峰值 −1.6862（原始比力模长约 8.1272） | 相邻变化分解：测量变化贡献约 **−1.71025**，姿态变化约 **+0.00017** → 主要来自**输入测量**而非姿态跳变 |
| 桌面 004616，约 52.134 s | X 峰值 −1.0920（原始比力模长约 9.5541） | 测量变化约 **−1.20653**，姿态变化约 **+0.02399** → 同样主要来自输入测量 |

> 以上是**数值贡献的定位，不是已确定的物理原因**。不能据此断言用户动了、
> 传感器坏了或网络丢包了。原始数据与标签保持不变。
> These identify numerical contributions, not physical causes.

> **复现范围**：残差贡献分解当时用临时计算完成，**尚未**保存成一键诊断脚本；
> 现有回放可复现窗口统计。不要说"所有分析都有复现工具"。

## 6. 证据规则 / Evidence rules

| 规则 | 说明 |
|---|---|
| **计划 ≠ 实际** | 指令里写的动作是计划；以用户报告的实际动作为准；只有计划时明确标注"计划，未独立确认" |
| **电脑接收相对时间** | 区间秒数以首包到达为 0，不是墙上时钟，也不是动作真值 |
| **平台识别是核对，不是标签** | 自动识别的静止平台用于交叉检查；用户确认优先 |
| **佩戴 vs 手持** | 手持朝向由手决定，**不能**作为安装依据 |
| **用户确认优先** | 例如 003433 的 2–6 s 由用户明确确认身体与模块静止，该事实保留，不因读数波动改写 |
| **不扩展确认范围** | 003433 的静止确认**不**扩展到其它时间；另一录制约 34.5 s 的澄清属于不同录制，不可混用 |
| **保留全部数据** | 不删尖峰、不按检测颜色筛选、不强制归零 |
| **区分记录时间与实验时间** | 文档整理时间不等于实验发生时间 |

## 7. 复现命令 / Reproduction

```powershell
$repoRoot = "<本仓库在本机的路径 / path to this repository>"
$py = "python"
Set-Location $repoRoot

# 六轴曲线
& $py -X utf8 "$repoRoot\visualize_imu.py" --recordings "$repoRoot\live_recordings"

# 数据完整性、序号、节点时间间隔
& $py -X utf8 "$repoRoot\check_pregravity.py"

# 姿态回放（含去重力）
& $py -X utf8 "$repoRoot\check_attitude_replay.py"

# 16 窗口去重力统计
& $py -X utf8 "$repoRoot\validate_gravity_removal.py"

# 静止平台速度漂移诊断
& $py -X utf8 "$repoRoot\validate_velocity_drift.py"

# 零偏标定窗口敏感性
& $py -X utf8 "$repoRoot\diagnose_gyro_bias.py"

# 联合单元测试
& $py -m unittest test_gravity_removal test_attitude test_stationary_stream `
        test_zupt_offline test_train_zupt test_velocity_propagation
```

> 以上命令**都不需要连接 ESP32**，也不需要重新录制。
> None of these commands require hardware.

## 安装变换 / Mounting transform

`attitude.R_BS` 把传感器系向量转到身体系（`+x` 前 / `+y` 左 / `+z` 上）：

```text
sensor +X -> body -z
sensor +Y -> body +y
sensor +Z -> body -x
```

最终依据 / final basis（2026-10-12 定稿）：

1. 用户确认的板面丝印朝向：**佩戴时 +X 向上、+Y 向左、+Z 向后**，丝印面朝腿外；三向满足
   右手系，安装旋转唯一确定，行列式 +1。
2. 实测交叉验证：真实佩戴的站立录制 `20261011_233919_343102_live` 比力
   `(+0.993, +0.102, -0.057)` 按本映射得到身体系 `(+0.057, +0.102, +0.993)`，朝上、离竖直
   6.7 度；坐姿大腿竖直一组得到竖直分量 `0.965`，同样朝上。
3. 平放与佩戴的关系：平放（丝印面朝上、x 箭头朝前）时 +Y 朝右手方向、+Z 垂直向下；佩戴姿态
   相对平放绕 y 轴转 90 度，故 +Y 转向左、+Z 转向后。
4. `20261012_025851` 坐姿手持录制按本映射其「大腿水平」一组竖直分量为 `-0.002`，与佩戴姿态
   不同，故仅作算法交叉检查，不作为安装依据；该次手持朝向待确认。

**仍未由六轴确定**：绕传感器 x 轴的 180°。大腿的自然转动（前抬、后摆、转体）全部绕这条轴，
对重力方向没有影响，因此该二义性在六轴数据中不可观测；需磁力计或 UWB 等外部观测复核。

**已知限制**：该 180° 不影响去重力、速度传播与零速度更新（它们只依赖 x 轴与垂直于重力的
分量），只影响身体左右/前后两个标签的符号。

## 已修正的缺陷 / Defects fixed

1. 安装矩阵轴对应错误（行列式虽为 +1，但把 +X 映射到了身体 +z 而非 -z）。
2. 重力校正的误差叉积方向反了，形成正反馈，合成静止输入即可把姿态推到 80 度。
3. 四元数积分乘法顺序反了（`q⊗ω` 应为 `ω⊗q`），yaw 朝陀螺相反方向增长。
4. 不可观测方向（沿重力）的零偏自由积分并污染 yaw；现改为只保留可通过静止标定的重直分量。
5. 六轴无航向观测，因此有效转速沿竖直轴的分量被清零，静止段 yaw 不再漂移。

以上五点均有单元测试覆盖，且用真实录制复核。
All five are covered by unit tests and re-checked against the recordings.
